## 분야 소개

서버와 프로그램 실행에 필요한 연산 자원, 물리·가상 실행 환경, AI 컴퓨팅 시스템의 개념을 정리합니다.

## 문서 목록

- [[Server|서버]]: 서버의 역할·종류·작동 원리와 발전 과정
- [[CPU]]: 프로그램의 명령을 실행하는 처리 장치
- [[Memory|메모리]]: 실행 중인 코드와 데이터를 보관하는 주기억장치
- [[Physical Server Configuration|물리 서버 구성]]: 서버 내부 부품과 데이터센터 랙의 연결 구조
- [[Virtualization|가상화]]: 물리 자원을 추상화해 여러 독립 실행 환경을 만드는 기술
- [[Hypervisor|하이퍼바이저]]: VM의 실행과 물리 자원 접근을 중재하는 계층
- [[Virtual Machine|가상 머신(VM)]]: 가상 하드웨어 위에서 독립된 OS와 프로그램을 실행하는 환경
- [[Bare Metal|베어메탈]]: 운영체제나 하이퍼바이저가 물리 서버를 직접 사용하는 환경
- [[Linux|리눅스]]: 커널·사용자 공간·부팅과 명령 실행의 전체 관계
- [[Linux Structure|리눅스 구조]]: 하드웨어·커널·사용자 공간과 프로그램 실행 계층
- [[Linux Directory Structure|리눅스 디렉터리 구조]]: `/` 아래의 마운트 구조와 주요 디렉터리의 역할
- [[CLI]]: 명령·옵션·인수와 표준 입출력·파이프·리다이렉션을 사용하는 인터페이스
- [[Linux Basic Commands|리눅스 기본 명령어]]: 파일·텍스트·프로세스·시스템 상태를 다루는 기본 명령
- [[Kernel|커널]]: 하드웨어 자원을 관리하고 시스템 호출을 제공하는 운영체제 핵심
- [[Firmware|펌웨어]]: 특정 하드웨어를 초기화하고 제어하는 장치 소프트웨어
- [[BIOS and UEFI|BIOS·UEFI]]: 운영체제보다 먼저 플랫폼을 초기화하는 펌웨어 방식
- [[Bootloader|부트로더]]: 운영체제 커널을 메모리에 적재해 실행하는 프로그램
- [[Program and Process|프로그램과 프로세스]]: 저장된 코드와 실행 중인 인스턴스의 구분
- [[Terminal|터미널]]: 문자 입력과 출력을 전달·표시하는 끝점
- [[Shell|셸]]: 명령을 해석하고 프로그램 실행 환경을 연결하는 프로그램
- [[Compilation|컴파일]]: 소스 코드를 실행 가능한 낮은 수준의 코드로 변환하는 과정
- [[Web Server|WEB]]: HTTP 요청·정적 콘텐츠·리버스 프록시
- [[Web Application Server|WAS]]: 업무 코드·동시 요청·연결 풀·애플리케이션 운영

- [[Shell Script|셸 스크립트]]: 명령 실행과 반복 작업 자동화

- [[AI Factory]]: 데이터부터 AI 결과까지의 인프라·운영 체계
- [[NVIDIA Reference Architecture]]: AI 인프라의 통합 참조 설계
- [[GPU Farm]]: 여러 GPU 서버를 모은 연산 인프라
- [[DGX]]: NVIDIA 통합 AI 시스템·플랫폼
- [[HGX]]: 파트너 서버용 GPU 플랫폼
